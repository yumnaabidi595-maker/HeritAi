# 🏛️ HeritAI

### AI-Powered Heritage Monitoring & Preservation

HeritAI is an AI-based heritage technology prototype designed to help document heritage structures and identify potential visible signs of deterioration from images.

## 🔍 What HeritAI Does

- Upload an image of a heritage structure
- Analyze visual characteristics of the structure
- Detect possible crack-like or irregular edge patterns
- Generate a preliminary condition assessment
- Display image-based visual metrics
- Support digital documentation of heritage sites

## ⚙️ How It Works

**Image Upload → Visual Analysis → Pattern Detection → Condition Assessment**

## 🧠 Current Technology

- Python
- Streamlit
- NumPy
- Pillow
- Image-processing based visual analysis
